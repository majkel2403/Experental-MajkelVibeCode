# Jarvis Orb Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an isolated dual-renderer Orb laboratory with truthful DEMO/REPLAY modes, cinematic WebGL rendering and a separately gated read-only LIVE integration.

**Architecture:** React Studio controls a normalized event reducer and MotionDirector. Classic SVG/Motion and Cinematic React Three Fiber renderers consume the same snapshot; transport adapters cannot execute commands. LIVE requires a separately reviewed, explicitly authorized read-only channel.

**Tech Stack:** React, TypeScript, Vite, Vitest, Testing Library, Motion, Three.js, React Three Fiber, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-08-orb-lab-design.md`

## Global Constraints

- Work only on `experiment/orb-lab`; application files only under `experiments/orb-lab/` and documentation under `docs/superpowers/`.
- No modifications to Jarvis production UI, bridge security, credentials or `main`.
- DEMO must work without Hermes. REPLAY cannot emit production events.
- LIVE is read-only, explicitly authorized and separately security-reviewed before activation.
- Preserve reduced-motion support, screen-reader state text, keyboard operation, mobile layout.
- Audio is normalized 0..1; never claim synthetic amplitude or events are real.
- Use TDD (red, green, refactor) and commit each verified task.

## Review Focus

1. Duplicate or out-of-order events across tasks must not regress current state — Task 2 tests.
2. Invalid amplitude (NaN, infinity, negative, >1) must clamp safely — Task 3 tests.
3. A missing WebGL context must leave Classic and controls functional — Task 7 tests.
4. Hidden tab or reduced-motion preference must stop perpetual GPU/timer activity — Tasks 5 and 8 tests.
5. Disconnected or malicious LIVE input must not trigger writes or expose credentials — Task 10 tests.
